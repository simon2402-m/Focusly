# Control de versiones de Focusly

## Herramienta utilizada

Git permite registrar los cambios realizados durante el desarrollo de Focusly.

GitHub se utiliza como plataforma para almacenar el repositorio y facilitar el acceso al código fuente.

## Flujo de trabajo

1. Realizar modificaciones en el proyecto.
2. Revisar los archivos modificados.
3. Preparar los cambios con `git add`.
4. Registrar los cambios con `git commit`.
5. Enviar los cambios al repositorio remoto con `git push`.

## Importancia

El control de versiones permite:

- Mantener un historial de modificaciones.
- Identificar cambios realizados.
- Recuperar versiones anteriores.
- Facilitar el trabajo de desarrollo.
- Mantener una copia remota del proyecto.

## Repositorio

El código fuente de Focusly se encuentra almacenado en GitHub.
