# Mejoras futuras de Focusly

Focusly puede seguir evolucionando mediante nuevas herramientas y mejoras.

## Mejoras propuestas

1. Incorporar notificaciones para recordar fechas límite.
2. Añadir estadísticas más detalladas sobre productividad.
3. Mejorar las recomendaciones personalizadas de inteligencia artificial.
4. Permitir exportar horarios y tareas.
5. Incorporar nuevas opciones de personalización.
6. Mejorar la experiencia en dispositivos móviles.

## Propósito

Estas mejoras buscan ampliar las funcionalidades de Focusly y ofrecer una experiencia cada vez más útil para los estudiantes.

## Visión a futuro

Convertir Focusly en una herramienta integral de organización académica que facilite la planificación y el seguimiento de objetivos.
