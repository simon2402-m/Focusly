# Pruebas de Focusly

## Objetivo

Comprobar que las principales funcionalidades de Focusly funcionan correctamente.

## Pruebas propuestas

| Funcionalidad | Comprobación |
|---|---|
| Registro | Verificar la creación de usuarios |
| Inicio de sesión | Comprobar el acceso a la cuenta |
| Tareas | Crear, editar y eliminar tareas |
| Prioridades | Comprobar los niveles de prioridad |
| Horarios | Registrar y modificar actividades |
| Progreso | Verificar los indicadores de actividad |
| Asistente IA | Enviar consultas y recibir recomendaciones |
| Propuestas IA | Comprobar la confirmación o cancelación de tareas |

## Registro de resultados

Las pruebas deben realizarse en el navegador y los resultados deben anotarse según el comportamiento observado.

No se deben marcar como exitosas las pruebas que todavía no se hayan realizado.
