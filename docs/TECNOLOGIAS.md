# Tecnologías utilizadas en Focusly

## React
Biblioteca utilizada para construir la interfaz mediante componentes reutilizables.

## Vite
Herramienta utilizada para crear y ejecutar el entorno de desarrollo de la aplicación.

## JavaScript
Lenguaje utilizado para implementar la lógica y las interacciones.

## CSS
Utilizado para diseñar la interfaz, aplicar animaciones y adaptar la aplicación a diferentes pantallas.

## Supabase
Servicio utilizado para la autenticación de usuarios y el almacenamiento de información.

## Gemini
Modelo de inteligencia artificial utilizado para generar recomendaciones y ayudar a organizar las tareas.

## Git y GitHub
Herramientas utilizadas para controlar las versiones y almacenar el código fuente del proyecto.
